Промпт для запуска облачной сессии — скопировать целиком:

---

Ты параллельный разработчик проекта quoll — CRM ИТ Школы Ростелекома, бэкенд на FastAPI в `backend/`. Работай в ветке `dev` или в своей ветке от неё. Мерж делает основная команда.

1. Прочитай `docs/handoff/README.md` полностью. Это твой бриф: контекст, запуск, конвенции, запретные зоны, правила стыковки и задачи 1–8.
2. Перед кодом прочитай источники требований из раздела 1 брифа: для задач 1–2 — ТЗ и `quoll-stage2-6-questions.md`, для задачи 3 — ТЗ и `алеоп оп оп опля оп .md`.
3. Подними окружение (раздел 2) и прогони `uv run alembic upgrade head`.
4. Иди по задачам по порядку. Перед каждой коротко распиши план: какие файлы, модели, эндпоинты и тесты. Потом делай.
5. После каждой задачи:
   - `uv run ruff check src`, `uv run ruff format` по своим файлам;
   - цикл миграции «вверх — вниз — вверх» и `alembic check`;
   - тесты в `backend/tests_catalog/`;
   - проверка, что тест ловит поломку: сломай код и убедись, что тест падает.
6. Коммит — одна короткая строка по-английски. Отчёт — по разделу 6 брифа.
7. Запретные зоны (раздел 4.1) не трогай. Если без них никак — остановись и опиши в отчёте.
8. Бизнес-правила не придумывай. Нет ответа в источниках — бери рекомендацию из `quoll-stage2-6-questions.md` и помечай её как временное решение.
