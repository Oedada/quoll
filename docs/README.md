## Оглавление

Разделы 1–7 описывают задачу, роли, маршрут работы с вузом, модель данных, обработку данных и интеграции. Разделы 8–15: архитектура, стек, API, безопасность, производительность, ограничения и установка. Разделы 16 и 17: руководства пользователя и администратора. Приложение 1: схемы базы данных, Приложение А: коды ошибок; приложение Б: примеры JSON; приложение Г: диаграммы последовательностей.
