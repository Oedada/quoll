    API: Swagger UI

    Все методы системы доступны и описаны в Swagger UI - он строится автоматически из кода сервиса. Схема API в формате OpenAPI доступна отдельным файлом.

    Как открыть

    • Swagger UI: https://quoll.oedada.ru/docs; схема OpenAPI: https://quoll.oedada.ru/openapi.json. Страница открывается без входа: список методов, параметры и схемы видны сразу. • Все методы работы с данными - под префиксом /api/v1.

    Как вызвать методы

    1. Откройте https://quoll.oedada.ru/auth/: откроется страница входа Keycloak.
    2. Войдите под демо-учётной записью нужной роли - КАМ, руководитель или администратор; логины - на странице входа и в README.
    3. Вернитесь на /docs: кнопка «Try it out» работает от имени вошедшего пользователя, браузер передаёт куки сессии.
    4. Выход - метод POST /auth/logout.

    Набор доступных действий зависит от роли, права проверяются на сервере. Если прав нет, метод вернёт ошибку 403, а в интерфейсе пользователь увидит текст и код ошибки (см. приложения А.)

    Что описано

    Всего представлено около 140 методов. У каждого в Swagger видны адрес, параметры, схемы запроса и ответа. Методы обмена с LMS и сайтом и выгрузки результирующего JSON появятся после слияния интеграций.
