    Технические ошибки

    Для всех технических кодов сообщение одно: «Не удалось выполнить действие ({код}). Повторите; если не получится, сообщите администратору». Что именно пошло не так, администратор видит в журнале приложения (по коду и времени).

    Коды Описание
    с AUTH-016 по AUTH-019 сбой или недоступность сервиса входа (Keycloak), чужое уведомление.
    AUTH-016 не показывается: сессия обновляется сама.
    с ORG-011 по ORG-014 неверный запрос при настройке команд и лимитов.
    с APP-033 по APP-040 неверный запрос к заявке: шаг чужого маршрута, неверная цель
    закрытия, возврата или переоткрытия, неверные поля запроса.
    с BR-006 по BR-010 неверный запрос к ветке.
    с DOC-009 по DOC-012 неверный запрос к документам и их версиям.
    с SYS-004 по SYS-014 запись не найдена, ограничение базы данных, непредвиденная
    ошибка сервера, сбой файлового хранилища.
